Open any Shopify merchant forum and the complaint is the same.

Not "I need more apps."

"I need the ones I already pay for to work together."

That is the entire job of Shopify integration partners. Reviews. Email. Loyalty. Support handoff. You bought those. The shopper still has to go find them. Stars below the fold. A popup they closed. Points they never check. A support ticket that starts from zero.

This post is one feature. The partner facts ride the conversation that is already happening on the page. How ShopGuide itself is integrated so those partners have a place to talk. What each one actually does for the merchant. What it will not do.

![A shopper in a store aisle, the place the conversation should already be](https://images.unsplash.com/photo-1556740738-b6a63e27c4df?w=1200&q=80)

## What merchants actually say

Public threads are blunt.

On r/shopify_growth a founder walked a store with 18 apps. Each one solved a small thing. Together they slowed the store and made the backend confusing. The useful comment was not "install a better app." It was that nobody on the team could say what half the apps even did anymore.

On r/shopifyDev the top reply to "what are merchants actually struggling with" was the small daily stuff. Messy integrations. Tracking mismatches. Too many apps doing half-jobs. The line that stuck: "Merchants don't want more tools they want ones that actually work together."

Loyalty gets the same treatment. A points program nobody used because customers could not see a balance without logging in. "The program existed but was essentially invisible. A loyalty program nobody interacts with is just a cost centre."

None of that is a request for a fifteenth widget. It is a request for the paid context to show up where the shopper already is.

## The feature: partners ride the on-page conversation

ShopGuide is an on-page agent. It lives in a theme block. It reads the live Shopify Catalog API during chat so stock, variants, and price match the warehouse.

Shopify integration partners attach to that same conversation. They do not get their own chat window. They do not get a second script farm.

The partner set on the [integrations page](https://blog.yourshopguide.com/integrations) is the list that exists today. Not a roadmap.

| Partner | What you bought it for | What the shopper usually sees | What ShopGuide does with it | How you connect it |
| --- | --- | --- | --- | --- |
| **Shopify Catalog API** | Products, stock, price | Search and filters | Live lookup of inventory, variants, and price during the reply | Native, nothing to connect |
| **Klaviyo** | Email, SMS, and onsite popups | A modal, then silence | Captures the email, tags the profile, fires named chat events | Private API key in settings |
| **Judge.me** | Verified reviews | Stars under the fold | Pulls a matching review and photo proof into the answer | Public API token in settings |
| **Rivyo** | Reviews and UGC | Same job, different app | Surfaces Rivyo proof inside the recommendation | Public API token in settings |
| **Smile.io** | Points and VIP tiers | A loyalty widget | Reads live balance and tier, answers "how many points do I have?" | API token in settings |
| **Alia** | Personalized incentives | A popup that gets closed | Keeps the Alia offer in context after the modal is gone | On when your polls are active |
| **Slack** | Team comms | A blank ticket | Posts customer, cart, and a transcript link for a handoff | Incoming webhook URL |

That is the merchant payoff.

The review that answers "does this run large" shows up in chat instead of on a tab the shopper never opens.

Points become a sentence ("you have 500 points, that is $5 off today") instead of a forgotten badge.

A closed popup is not a dead offer.

A human picks up with the transcript, cart, and customer instead of "please describe your issue."

On a small catalog this is polite. On a large one it is how the same question stops becoming a ticket.

Klaviyo is the clearest example because the docs name the payload. Three events: ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted. Profile fields that actually land include journey archetype, persona, last chat intent, key hesitation, and dietary tags. Dietary tags stay on verifiable attributes. Not a vibe the model guessed. Klaviyo still owns the flow. ShopGuide hands it the moment.

## How ShopGuide is integrated into Shopify

Three connections. Shopify integration partners only work because these three exist.

**1. Theme block.**

You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**2. Shopify Admin.**

The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, chat history, Integrations, Settings. Revenue attributed to chat sessions shows up there. There is no second login to babysit.

**3. Catalog API at talk time.**

The agent looks up products from Shopify's Catalog API during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. Sold-out SKUs should not get recommended as available.

That wiring is why the partner cards matter. The conversation is the place those facts get used.

## How to connect a partner

Open **ShopGuide → Settings → Integrations** in Shopify admin.

ShopGuide checks your published theme for app embeds it recognizes. Those apps land at the top under "Looks like you use these," with an **On your store** badge. That saves you hunting through logos. It does not connect anything by itself.

Then connect the ones you run:

- **Klaviyo:** paste a private API key with Profiles, Events, and Lists write access. Pick the newsletter list. The named events are ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted.
- **Judge.me and Rivyo:** paste the public API token from that app.
- **Smile.io:** generate an API token in Smile admin and paste it on the card.
- **Slack:** create an incoming webhook for the channel and paste the URL.
- **Alia:** on when your Alia polls are active. No token paste.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

New to ShopGuide? Install from the App Store listing, add the theme block, then confirm the catalog is syncing in the dashboard. The [docs](https://docs.yourshopguide.com/docs/advanced-features/ecosystem-integrations) walk the same steps.

## Honest limits

Say this before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read. Installing ShopGuide does not remove the scripts those apps already inject. The point is not a seventh app that does their jobs. The point is one place those facts get used.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified, and only for what the token can read. A first-time anonymous visitor has no points to surface. If Smile's plan hides that data, ShopGuide cannot invent it.

Klaviyo still owns the flow. ShopGuide hands it the moment. Follow-up only works if the shopper gives an email. Dietary tags only land on verifiable attributes, not on a lifestyle guess.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin, not by replying in Slack.

The Catalog API keeps stock honest. It does not write your descriptions. Dirty product data still produces thin answers.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**

The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**

Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**

No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**

Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on when polls are active.

**Does ShopGuide find my apps automatically?**

It badges apps it recognizes on your published theme, so you know which cards to fill in. You still paste the credentials.

**Will this add more scripts and slow the storefront?**

ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**

Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**

No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
