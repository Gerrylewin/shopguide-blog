The public list is on the [integrations page](https://www.yourshopguide.com/blogs/integrations). Six partners. That is the set that exists today.

| Partner | What you already bought | What connecting it does in chat | What you paste |
| :---------------------- | :---------------------- | :----------------------------------------------------------------- | :------------------- |
| **Shopify Catalog API** | Products, stock, price | Live lookup of inventory, variants, and price | Nothing. Native. |
| **[Klaviyo](https://www.yourshopguide.com/blogs/integrations/klaviyo-shopguide)** | Email and SMS | Captures the email, tags the profile, fires named chat events | Private API key |
| **[Judge.me](https://www.yourshopguide.com/blogs/integrations/judge-me-shopguide)** | Verified reviews | Pulls a matching review and photo proof into the answer | Public API token |
| **[Rivyo](https://www.yourshopguide.com/blogs/integrations/rivyo-shopguide)** | Reviews and UGC | Surfaces Rivyo proof next to the recommendation | Public API token |
| **[Smile.io](https://www.yourshopguide.com/blogs/integrations/smile-io-shopguide)** | Points and VIP tiers | Answers "how many points do I have?" with a live balance | API token |
| **[Alia](https://www.yourshopguide.com/blogs/integrations/alia-shopguide)** | Personalized incentives | Keeps the Alia offer in context after the popup is gone | On by default |
| **[Slack](https://www.yourshopguide.com/blogs/integrations/slack-shopguide)** | Team comms | Posts customer, cart, and a transcript link when a human is needed | Incoming webhook URL |

That table is the merchant value.
