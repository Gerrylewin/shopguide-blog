## The feature: Integrations finds the stack you already paid for

Open ShopGuide in the Shopify admin. Go to Settings, then Integrations.

The screen scans your published theme and storefront assets. App embeds that are already live (Klaviyo onsite scripts, Judge.me widgets, Smile.io launchers) rise to the top with an On your store badge.

That is the whole product surface. Not a second dashboard. A list of partners the agent can read during chat.

What you connect from there is the public partner set:

| Partner on the page | What you already use it for | What the agent does with it                                                                                               |
| :------------------ | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| **Klaviyo**         | Email, SMS, popups          | Captures an email in chat, can add it to a list, and can send Chat Engaged, Order Attributed, and NPS events into Klaviyo |
| **Judge.me**        | Verified reviews            | Pulls matching reviews and photo proof into the reply                                                                     |
| **Rivyo**           | Reviews and UGC             | Same job if Rivyo is the review app you run                                                                               |
| **Smile.io**        | Points and VIP tiers        | Reads live balance and tier so the agent can mention them                                                                 |
| **Alia**            | Personalized incentives     | Keeps the offer in the conversation after the popup is gone                                                               |
| **Slack**           | Team alerts                 | Posts customer, cart, and a transcript link when a handoff fires                                                          |

Most cards need a token from the partner admin. Smile.io wants an API token. Judge.me and Rivyo want their public API token. Klaviyo wants a private API key with Profiles, Events, and Lists write access, plus a default newsletter list. Slack wants an incoming webhook URL.

If the partner is not installed, there is nothing to detect. The agent still works on the catalog. It just will not invent reviews or points that do not exist.

Partner how-tos if you only need one pairing: [Klaviyo](/blog/klaviyo-shopguide-integration-guide), [Judge.me and Rivyo](/blog/social-proof-judgeme-rivyo-ai-agent), [Smile.io](/blog/smile-io-loyalty-ai-agent-automation), [Slack](/blog/slack-integration-customer-support-efficiency).

## How ShopGuide itself is wired into Shopify

Shopify app integrations only work if the agent already lives inside Shopify. ShopGuide does that in three places.

**Theme block.** You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**Shopify Admin.** The app sits in the sidebar. Home, Dashboard, Test your Guide, Settings. Chat-attributed revenue shows up there. You do not leave Shopify to see if a conversation produced an order.

**Live Catalog API.** During chat the agent looks up products from Shopify's Catalog API. Stock, variants, and price come from the store, not from a file you uploaded last Tuesday. A sold-out SKU should not get recommended as available. That wiring is the [live Catalog API post](/blog/live-catalog-api-keeps-agent-answers-accurate-high-sku-shopify).

Partners attach to that same conversation. They do not get their own chat window.

That is also why the public [integrations page](https://blog.yourshopguide.com/integrations) is short. Six partners. The jobs merchants already run: reviews, email, loyalty, offers, human backup.

## What that is worth to a merchant

High-SKU stores already run a lean version of the same kit. Email. Reviews. Points. Slack for the team. Maybe Alia if they use personalized offers.

The shopper still has to hunt.

Popup in one corner. Stars under the fold. A points widget they never open. A ticket that starts from zero when they finally ask for a person.

Shopify app integrations are useful when those facts show up in the path the shopper is already on.

- "Does this run large" gets a real Judge.me or Rivyo review in the reply, not a link to a tab they will not open.
- "You have 500 points, that is $5 off today" is a sentence, not a forgotten launcher.
- A closed Alia or Klaviyo popup is not a dead offer if the agent can bring the incentive back.
- A Slack handoff includes the transcript and the cart instead of "please describe your issue."
- A Klaviyo profile can pick up Chat Engaged, an attributed order, and an NPS score so the next email is not guessing.

On a 200-SKU boutique that is polite. On a 10,000-SKU catalog it is how the same sizing question stops becoming a ticket.

You do not have to connect every tile. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

## Honest limits

Say this before you paste any tokens.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or the token is wrong, there is nothing to read.

Reviews in chat are only as good as the reviews you have collected.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Slack is one-way. ShopGuide posts context into a channel. Your team still resolves in Shopify or the ShopGuide admin. You do not run the whole conversation from Slack replies.

Klaviyo does not invent a list. Capture and follow-up only work if Klaviyo is actually connected and the shopper gives an email.

The agent cannot invent metafields that live only inside another app and never in Shopify. Dirty product data still produces thin answers. The Catalog API keeps stock honest. It does not write your descriptions.

That is the deal. Native wiring. Partner context when it exists. Not a new operating system.

## Frequently Asked Questions

**What Shopify app integrations does ShopGuide support?**  
Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Catalog API. The current public list is on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**  
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Direct reads from the Shopify Catalog API during chat. Partner apps attach to that same conversation.

**How does automatic app detection work?**  
Settings, Integrations scans your published theme and storefront assets for known app embeds. Detected apps show up first with an On your store badge. You still paste tokens for Smile.io, Judge.me, Rivyo, Klaviyo, and Slack.

**Do I have to replace my current apps?**  
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**Will this add more scripts and slow the storefront?**  
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems, not another pixel farm.

**What if I only use some of the partners?**  
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**  
No. Slack gets a structured alert with context and a link to the transcript. Resolution stays in Shopify or the ShopGuide admin so history lives in one place.
