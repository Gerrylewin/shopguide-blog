Shopify merchants are tired of the app tax.

Not the dollar amount. The half-jobs.

You pay for Klaviyo. You pay for Judge.me. You pay for Smile.io. Then a shopper has to hunt for the popup, the stars under the fold, the points widget they never open, and the support ticket that starts from zero.

That is what Shopify integration partners are for. Not a new logo on a page. The stack you already bought showing up where the shopper is deciding.

On r/shopifyDev someone asked what merchants were actually struggling with. The top reply: messy integrations, tracking mismatches, too many apps doing half-jobs. "Merchants don't want more tools they want ones that actually work together."

On r/ecommerce a merchant with Klaviyo, a loyalty app, and a review app said the data syncs. The apps still do not reason across it. Someone else gets paid a few thousand a month to glue the segments by hand.

On r/shopify_growth a store had 18 apps. Each one solved a small thing. Together they slowed the store and made the admin confusing. Cleaning the stack helped more than adding another install.

So that is what people want to read. How the apps they already pay for can talk.

## The feature: partners ride the on-page conversation

ShopGuide is an on-page agent. One theme block. It reads the live Shopify Catalog API while the shopper talks. Stock. Variants. Price.

Shopify integration partners attach to that same turn. They do not get a second bubble. They do not get their own script farm.

The public list is on the [integrations page](https://blog.yourshopguide.com/integrations). Six partners. No coming soon row.

**Judge.me.** Verified reviews and photo proof inside the answer. The shopper asks if a jacket runs large. The reply can quote a real review instead of guessing. You paste a public API token.

**Rivyo.** Same job if Rivyo is your review app. UGC rides the recommendation instead of living under the fold.

**Klaviyo.** The conversation does not die when the visitor leaves. Newsletter capture. Profile tags from what they asked. The events the docs actually name: ShopGuide Chat Engaged, ShopGuide Order Attributed, ShopGuide NPS Submitted. Klaviyo still owns the flow. ShopGuide hands it the moment.

**Smile.io.** Live points balance. VIP tier. What Gold actually gets them. A shopper can ask "how many points do I have?" and get a number. You generate an API token in Smile and paste it on the card.

**Alia.** Personalized incentives stay in context after the popup closes. Alia stays the personalization engine. ShopGuide reads what you already decided to show that visitor.

**Slack.** Stuck thread. High cart. "I want a human." Slack gets the alert with customer, cart, and a transcript link. Your team does not reply inside Slack. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.

That is the merchant payoff of Shopify integration partners done this way.

The review that closes the sale shows up in the chat.

Dormant points become a sentence.

A closed popup is not a dead offer.

A human picks up with the transcript instead of "please describe your issue."

On a 200-SKU boutique this is polite. On a 10,000-SKU catalog it is how the same question stops becoming a ticket.

## How ShopGuide is integrated into Shopify

Three connections. Shopify integration partners only work because these three exist.

**1. Theme block.**
You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home. Analytics. Test your Guide. Chat history. Integrations. Settings. Revenue attributed to chat sessions shows up there. There is no second login to babysit.

**3. Catalog API at talk time.**
The agent looks up products from Shopify's Catalog API during the conversation. Partner context attaches to that same reply. Sold-out SKUs should not get recommended as available.

Open **ShopGuide → Settings → Integrations** and the app scans your published theme for embeds it recognizes. Detected apps land at the top under "Looks like you use these" with an **On your store** badge.

The badge is a map. It does not invent credentials. You still paste a key or token for Klaviyo, Judge.me, Rivyo, and Smile.io. Slack still wants an incoming webhook URL. Alia is on when your Alia polls are active.

You do not have to connect every logo. A store on Judge.me and Klaviyo does not need Rivyo for the agent to be useful.

Docs also mention WhatsApp handoff and nine Sidekick tools inside Shopify Admin. Those are real. They are not tiles on the public partner page. The page is the six logos above. Sidekick is native Shopify.

## Honest limits

Say this before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Klaviyo still owns the email. Follow-up only works if the shopper gives an address.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin.

The Catalog API keeps stock honest. It does not write your descriptions. Thin product data still produces thin answers.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on when polls are active.

**Does ShopGuide find my apps automatically?**
It badges apps it recognizes on your published theme so you know which cards to fill in. You still paste the credentials.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
