You already pay for email. Reviews. Loyalty. Maybe a membership program.

The shopper rarely sees any of it while they decide. Stars sit below the fold. Points hide in a widget. The popup got closed on page one.

Shopify app integrations in ShopGuide fix one narrow thing. The agent on your store can use those apps inside the conversation. This guide covers what each connection does, what it needs from you, and where it stops.

No roadmap. Only what is in the product today.

![A pile of jigsaw puzzle pieces, the apps a Shopify store already runs](https://images.unsplash.com/photo-1494059980473-813e73ee784b?w=1200&q=80)

## What merchants keep saying

Merchants are not asking for more apps. They want the ones they have to work together.

On February 21, 2026, a thread on [r/shopifyDev](https://www.reddit.com/r/shopifyDev/comments/1rarbr9/what_are_merchants_actually_struggling_with_in/o6m1f9v/) asked what merchants actually struggle with. u/EngineeringHuge1331 listed messy integrations and too many apps doing half-jobs. Then: "Merchants don't want more tools they want ones that actually work together."

A month later, on [r/ecommerce](https://www.reddit.com/r/ecommerce/comments/1s3pwbo/anyone_else_feel_like_their_apps_should_be/), u/Lacicek described a store running Klaviyo, LoyaltyLion, and Yotpo. All connected. "Data flows fine. But the apps don't reason across the combined data to make decisions."

ShopGuide does not solve that whole problem. It does a smaller job. When a shopper asks a question, the agent can pull the review, the points balance, or the live offer from the app you already run, and answer with it.

## How the connection works

ShopGuide lives in two places in Shopify. A theme block on the storefront, where the chat runs. And an app in your Shopify admin, where you set it up.

Integrations are a tab on the Settings page.

ShopGuide checks your published theme for app embeds it recognizes. Those apps show at the top under "Looks like you use these" with an **On your store** badge. That is a hint, not a connection. Nothing turns on by itself.

You connect each app by pasting its API key or token on its card. No key, no connection. You can connect one app or all of them.

A few of these need more detail.

**Klaviyo is the only partner ShopGuide writes to.** A newsletter signup in chat goes to the list you pick. If the address is already subscribed, the agent says so instead of pretending it is new. You can type a signup reward like "10%" so the agent can mention it. Your Klaviyo welcome flow sends the actual code.

The profile properties start with `sg_`. Persona, top category, dietary tags, last chat intent, key hesitation. Three events fire: ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted. You decide what Klaviyo does with them. Klaviyo still owns the flows.

**Reviews stay honest.** When a shopper asks "does this run large?", the agent can quote a real review instead of guessing. It quotes 4 and 5 star reviews. It does not change the average or the count. If a product has no reviews, it says so.

**Loyalty and membership only work for a logged-in shopper.** The agent identifies the customer from their Shopify login, never from an email typed into chat. Otherwise anyone could ask for someone else's balance. If both Smile.io and Inveterate keys are saved, Inveterate is used.

**Slack is a handoff, not a conversation.** If the agent cannot help, it can send the request to your channel. That includes the shopper's message, their email, the priority, an order number if there is one, and a link to the full chat transcript in your admin. If no webhook is saved, it falls back to email.

## Honest limits

Read these before you paste a key.

- **Opt-in, one app at a time.** Nothing connects until you add the key. Detection on your theme is a guess based on app embeds. An installed app that is not on the theme will not get a badge.
- **Read-only for almost everything.** ShopGuide reads reviews, points, memberships, and offers. It does not write back. It will not post a review, redeem points, or touch a membership.
- **Klaviyo cart-abandon is not automatic yet.** The event exists. It is switched on per shop by our team, not from your settings. It is running as a pilot on one store. The scheduled job that would send it for every opted-in store is not running yet. Do not plan a flow around it today.
- **Your plan and your API set the ceiling.** If your Smile.io or Judge.me plan does not expose something through its API, ShopGuide cannot show it. An expired or wrong key means no data.
- **Empty apps give empty answers.** No reviews means no social proof. A loyalty program with no members has nothing to read.
- **It does not replace anything.** Klaviyo, Judge.me, and Smile.io keep their own widgets and scripts. ShopGuide reads them. It does not remove them.
- **Not every app is supported.** ShopGuide does not connect to Yotpo, Okendo, Loox, Stamped, LoyaltyLion, Gorgias, or Recharge today. If you run one of those, the agent cannot read it.

## Frequently Asked Questions

**What Shopify app integrations does ShopGuide support?**
Klaviyo, Judge.me, Rivyo, Smile.io, Inveterate, Upnova, Alia, and Slack. Each one does a specific job, listed in the table above.

**Do the integrations turn on automatically?**
No. Every integration is opt-in. Klaviyo, Judge.me, Rivyo, Smile.io, and Inveterate need a key or token pasted in Settings. Slack needs an incoming webhook URL. Upnova and Alia need no key, but only work if you already run them.

**Does ShopGuide write anything back to my apps?**
Only to Klaviyo. It can add newsletter subscribers, profile properties, events, and list members. It only reads from Judge.me, Rivyo, Smile.io, Inveterate, Upnova, and Alia.

**Can the agent redeem points or cancel a membership?**
No. It can tell a logged-in shopper their balance, tier, and what they can redeem. Redeeming stays in your loyalty app.

**Will ShopGuide send cart abandonment emails through Klaviyo?**
Not automatically yet. The cart-abandon event is in a pilot on one store and is switched on per shop by our team. Your normal Klaviyo cart flows keep working as before.

**Do I need every integration for ShopGuide to be useful?**
No. Connect the apps you run. A store with only Judge.me and Klaviyo is a normal setup.

**Does ShopGuide work with Yotpo, Okendo, Loox, Stamped, LoyaltyLion, Gorgias, or Recharge?**
Not today. Only the apps in the table are connected.

**Can my team reply to customers from Slack?**
No. Slack gets a one-way alert with the request. Your team replies to the customer by email.
