Shopify merchants are not short on apps.

They are short on the moment those apps show up when a shopper stalls.

That is the public complaint. A store audit with 18 installs that made the backend louder and the storefront slower. A thread about 37 apps and a quarterly purge. Operators saying the invoice is one problem and the extra dashboard is the other.

Nobody on those threads asked for a seventh review tool. They asked for Shopify integration partners that use the tools already on the invoice.

This post is one feature. Partner context inside the on-page agent. What connecting the partners on the [integrations page](https://blog.yourshopguide.com/integrations) actually does for the merchant, and how ShopGuide itself sits in Shopify so that context has a place to land.

## The feature: partner context at talk time

ShopGuide is an on-page agent. It is not a new operating system for your stack.

You install it from the Shopify App Store. You add the ShopGuide Chat section in the theme editor. Settings live in the Shopify admin sidebar. During the conversation the agent reads the live Shopify Catalog API. Stock, variants, metafields.

Shopify integration partners attach to that same turn.

Reviews from Judge.me or Rivyo. A Klaviyo capture or a later event. A Smile.io balance. An Alia incentive you already decided to show. A Slack ping when the agent is stuck.

The shopper does not open a new tab for any of it. That is the value. Not a fifteenth widget.

Open **ShopGuide → Settings → Integrations** if you want the setup view. Detected apps from the published theme land at the top under "Looks like you use these." Detection finds the logo. Tokens still come from you. Smile.io, Judge.me, and Rivyo need an API token. Slack needs an incoming webhook. Klaviyo needs a private key with Profiles, Events, and Lists write access.

Detection does not invent credentials. It stops you from hunting a wall of logos for tools you already published.

## How ShopGuide is wired into Shopify

Three connections. That is the product around the partners.

**1. Theme block.**
One ShopGuide Chat section. Launch messages, visibility, and styling live in the app admin. Partners are not copied onto the page as extra pixels.

**2. Shopify Admin.**
Home, Dashboard, Test your Guide, Chat History, Integrations, Settings. Analytics sit next to the rest of the store. There is no second login to babysit.

**3. Catalog API at talk time.**
The agent looks up the live catalog during the conversation. Partner facts ride that same turn. The catalog keeps stock honest. The partners keep social proof, loyalty, email, and handoff from living in a different window.

If you want the wiring writeup by itself, it already exists: [How ShopGuide is wired into Shopify app integrations](/blog/how-shopguide-is-wired-into-shopify-app-integrations). This post is the merchant payoff once that plug is in.

## What each partner buys the shopper

Keep the ones you run. Leave the rest alone. The public list is six cards.

| Partner | What you already paid for | What the shopper gets in chat |
| :------ | :------------------------ | :---------------------------- |
| **Judge.me** | Verified reviews and photo proof | A matching review in the answer, not a scroll to the widget |
| **Rivyo** | Reviews and UGC | The same job from Rivyo data, quoted in the recommendation |
| **Klaviyo** | Email and SMS | Capture in the conversation. Later events: ShopGuide Chat Engaged, ShopGuide Order Attributed, ShopGuide NPS Submitted |
| **Smile.io** | Points and VIP tiers | "How many points do I have?" gets a number. Gold has a meaning |
| **Alia** | Personalized incentives | The opening and the pick match the offer you already decided to show |
| **Slack** | A team channel | Stuck thread, high cart, or "I want a human" lands with transcript and cart |

**Judge.me and Rivyo.**
A shopper asks which moisturizer works for sensitive skin. The agent can quote a real review instead of inventing confidence. No token, no review text.

**Klaviyo.**
The conversation does not have to die when the visitor leaves. Newsletter capture on the storefront. Profile tags from what they asked. Klaviyo still owns the flow. ShopGuide hands it the moment.

**Smile.io.**
Points balance, VIP tier, what Gold actually gets them. You generate an API token in Smile.io and paste it on the Smile.io card.

**Alia.**
Alia stays the personalization engine. ShopGuide reads the context so the first line is not generic.

**Slack.**
Your team does not reply inside Slack. The alert has customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.

Docs also mention WhatsApp handoff and nine Sidekick tools inside Shopify Admin. Those are real. They are not on the public partner page. The page is the six logos above. Sidekick is native Shopify, not a third-party tile.

## Honest limits

Say this before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner is missing or misconfigured, there is nothing to read.

Detection only sees what is in the published theme and storefront assets. An app sitting installed but unpublished will not badge itself.

Reviews in chat are only as good as the reviews you collected.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Slack is one-way. ShopGuide posts context. Your team still resolves in Shopify or the ShopGuide admin.

Klaviyo does not invent a list. Follow-up only works if Klaviyo is actually in the store and the shopper gives an email.

Dirty product data still produces thin answers. The Catalog API keeps stock honest. It does not write your descriptions.

A partial stack still works. You do not need every logo.

That is the deal. Native wiring. Partner context when it exists.

## Frequently Asked Questions

**What are ShopGuide Shopify integration partners?**
The six apps on the [integrations page](https://blog.yourshopguide.com/integrations): Rivyo, Judge.me, Klaviyo, Smile.io, Alia, and Slack. They attach to the same on-page conversation as the Shopify Catalog API.

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Direct reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. Partners are not copied onto the page as extra pixels. The agent reads those systems during the conversation.

**How do I turn a partner on?**
Install both apps. Detection badges what it finds on the published theme. Smile.io, Judge.me, and Rivyo still need an API token. Slack needs an incoming webhook URL. Klaviyo needs a private API key.

**What if I only use some of the partners?**
Use the ones you run. A partial stack still works. You do not need every logo on the page.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
