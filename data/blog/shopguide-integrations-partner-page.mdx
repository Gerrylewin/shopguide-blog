Look. Shopify merchants are not sitting down hoping to read another AI listing.

They are sitting down hoping someone will admit the stack is already paid for, and still silent.

That is the thread that keeps showing up in public. On r/shopify_growth a merchant wrote that their tech stack was bigger than the team running it. Apps for upsells, reviews, email, SMS, loyalty, returns, landing pages. Then the trade-offs showed up. Site speed. Conflicts. Tracking nobody trusted. Nobody on the team could draw the map.

On r/shopifyDev the first reply to "what are merchants struggling with" was messy integrations, tracking mismatches, and too many apps doing half-jobs. The punchline: merchants do not want more tools. They want ones that work together.

ShopGuide integrations exist for that gap. Not a fifteenth widget. A place for the tools you already run to speak while the shopper is still deciding.

## One feature: ShopGuide integrations on the live partner page

ShopGuide is an on-page agent. You add a Chat section in the theme editor. The admin lives in the Shopify sidebar. During a conversation the agent looks up products on the Shopify Catalog API so stock, variants, and price match the warehouse, not a file from last Tuesday.

ShopGuide integrations attach to that same conversation. They do not get their own chat window.

The current set is the list on the [integrations page](https://blog.yourshopguide.com/integrations). Same cards as [integrations.yourshopguide.com/shopify](https://integrations.yourshopguide.com/shopify). No "coming soon" row.

## How ShopGuide itself is integrated

Three connections. ShopGuide integrations only work because these three exist.

**1. Theme block.**  
You install from the Shopify App Store. You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script farm for every partner.

**2. Shopify Admin.**  
The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, Integrations, Settings. Chat-attributed revenue shows up there. Review-app tokens live on the Integrations screen. You do not leave Shopify to see if a conversation sold anything.

**3. Live Catalog API.**  
The agent queries Shopify's Catalog API for the products in play. Sold-out SKUs should not get recommended as available. Dirty titles still produce thin answers. Live stock is the part the API can keep honest.

Most pairings activate when both apps are installed. Slack is the exception. That one needs an incoming webhook URL in ShopGuide settings.

There is a second Klaviyo path that is easy to miss if you only look at the storefront chat. Path Explorer can sync reachable segments into a Klaviyo list with cohort properties. Cart abandoners and chat-assisted buyers can land in a flow you already run. That is documented. It is not a promise that every anonymous browser becomes a profile.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

## Why merchants care

High-SKU operators already run a lean version of the same kit. Email. Reviews. Loyalty. A channel for the team. Maybe a popup tool.

The complaint is not "I hate apps." It is paying for tools that never share context at the moment the shopper hesitates.

Popup in one corner. Stars below the fold. Points in a widget they never open. A human ticket that starts from zero.

ShopGuide integrations do not ask you to rip Klaviyo out. They ask the agent to use Klaviyo. Same for reviews and points.

The useful test is boring. Can the shopper hear the thing you already paid for without opening another tab?

## Honest limits

Say this before you flip switches.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or the token is wrong, there is nothing to read.

Reviews in chat are only as good as the reviews you collected.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Slack is one-way. ShopGuide posts context into a channel. Your team still resolves in Shopify or the ShopGuide admin. You do not run the whole conversation from Slack replies.

Klaviyo does not invent a list. Popup recovery needs Klaviyo actually on the store. Path Explorer sync only pushes reachable people, the ones with an email or a Shopify customer id.

The agent cannot invent metafields that live only inside another app and never in Shopify. The Catalog API keeps stock current. It does not write your descriptions. Details on that live in the [live Catalog API post](/blog/live-catalog-api-keeps-agent-answers-accurate-high-sku-shopify).

ShopGuide integrations are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are ShopGuide integrations?**  
They are the apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public cards live on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**  
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics, settings, and partner tokens. Direct reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**  
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**  
Install both apps. Most pairings activate when both are live. Slack needs a webhook URL pasted into ShopGuide settings. Review apps use tokens on the Integrations screen in the admin.

**Will this add more scripts and slow the storefront?**  
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems, not another pixel farm.

**What if I only use some of the partners?**  
Use the ones you have. Partial stacks still work.

**Can Path Explorer send people to Klaviyo?**  
Yes, for reachable segments. ShopGuide pushes known emails into a Klaviyo list with cohort properties. Anonymous browsers with no email do not become profiles.

**Does Slack let my team reply inside Slack?**  
No. Slack gets a structured alert with context and a link to the transcript. Resolution stays in Shopify or the ShopGuide admin so history lives in one place.
