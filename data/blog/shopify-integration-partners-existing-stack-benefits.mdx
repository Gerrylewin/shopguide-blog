You already bought the stack.

Klaviyo for the list. Judge.me or Rivyo for the stars. Smile.io for the points. Alia for the offer that pops. Slack so the team knows when something is stuck.

Then the shopper hits the product page and none of that shows up in the moment that matters.

The popup closes. The reviews sit under the fold. The points widget needs a login. The human ticket starts from zero.

That is the complaint that shows up on Reddit every month. Not "I need a better chatbot." "Why don't the apps I already pay for talk to each other?"

On r/shopifyDev the top answer to "what are merchants actually struggling with" was messy integrations and too many apps doing half-jobs. The follow-up line was blunt: merchants do not want more tools. They want ones that work together.

A store with 18 apps on r/shopify_growth cleaned the stack and saw more lift than adding another install. The person who installed half of them had already left. Nobody left could say what the other half still did.

Loyalty gets the same treatment. A points program that lives in a widget nobody opens is just a cost center. One merchant wrote that customers could not see a balance without logging in, so the program was invisible. Another said Smile.io only worked if someone was already looking for it.

So the job is not another logo. The job is to put the paid context where the shopper already is.

## The feature: partners ride the on-page conversation

ShopGuide is one theme block. You drop the Chat section in the theme editor. It opens on the page the shopper is on. It reads the live Shopify Catalog API while they talk so stock, variants, and price match the warehouse right now.

The partners on the [integrations page](https://blog.yourshopguide.com/integrations) attach to that same conversation. They do not get a second bubble. They do not inject another script farm.

Here is what each one actually does when you connect it:

| Partner | What you already pay for | What the shopper sees without it | What happens in the chat |
| --- | --- | --- | --- |
| **Shopify Catalog API** | Products, stock, price | Search and filters | Live lookup during the reply |
| **Klaviyo** | Email, SMS, popups | Modal, then silence | Captures the email, tags the profile, fires the named events |
| **Judge.me** | Verified reviews | Stars under the fold | Pulls a matching review and photo proof into the answer |
| **Rivyo** | Reviews and UGC | Same job, different app | Surfaces Rivyo proof inside the recommendation |
| **Smile.io** | Points and VIP tiers | A widget they never open | Answers "how many points do I have?" with the live balance |
| **Alia** | Personalized incentives | A popup that gets closed | Keeps the offer in context after the modal is gone |
| **Slack** | Team alerts | A blank ticket | Posts customer, cart, and a transcript link |

That is the merchant payoff.

The review that answers "does this run large" shows up in the reply instead of on a tab the shopper never opens.

Points become a sentence. "You have 480 points. That is $4.80 off today."

A closed popup is not a dead offer. The discount stays in the conversation.

A human picks up with the transcript and the cart instead of asking the shopper to describe the issue again.

On a 200-SKU boutique this is polite. On a 10,000-SKU catalog it is how the same question stops becoming a ticket.

Klaviyo is the clearest example of the handoff. The docs name three events: ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted. Profile fields that actually land include the journey archetype, last chat intent, and key hesitation. Dietary tags stay on verifiable attributes (gluten-free, certified organic). Not a vibe the model guessed. Klaviyo still owns the flow. ShopGuide hands it the moment.

## How ShopGuide is wired into Shopify

The partners only work because ShopGuide lives inside Shopify, not beside it. Three connections.

**1. Theme block.**
You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, chat history, Integrations, Settings. Revenue attributed to chat sessions shows up there. There is no second login.

**3. Catalog API at talk time.**
The agent looks up products from Shopify's Catalog API during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. Sold-out SKUs should not get recommended as available.

Open **ShopGuide → Settings → Integrations**. The app scans your published theme for embeds it recognizes. Detected apps land at the top under "Looks like you use these" with an **On your store** badge. That saves you hunting through logos. It does not connect anything by itself.

Then you paste the credential for the ones you run:

- **Klaviyo:** private API key with Profiles, Events, and Lists write access. Pick the newsletter list.
- **Judge.me and Rivyo:** public API token from that app.
- **Smile.io:** API token from Smile admin.
- **Slack:** incoming webhook URL for the channel.
- **Alia:** on when your polls are active. No token paste.

You do not have to connect every logo. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

The public list is the six partners above. Docs also mention WhatsApp handoff and Sidekick tools inside Shopify Admin. Those are real. They are not tiles on the integrations page. Sidekick is native Shopify.

## Honest limits

Say this before you paste a key.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read. Installing ShopGuide does not remove the scripts those apps already inject.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface. If the Smile plan hides the balance from the customer, ShopGuide cannot invent it.

Klaviyo still owns the email. Follow-up only works if the shopper gives an address.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin so the history lives in one place.

The Catalog API keeps stock honest. It does not write your descriptions. Dirty product data still produces thin answers.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on when polls are active.

**Does ShopGuide find my apps automatically?**
It badges apps it recognizes on your published theme so you know which cards to fill in. You still paste the credentials.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
