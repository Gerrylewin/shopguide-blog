Merchants do not sit around wishing for another app.

They sit around wishing the ones they already pay for would show up in the same place.

That is the whole point of Shopify app integrations. Email. Reviews. Loyalty. Support. You bought the seats. The shopper still has to hunt. Popup in one corner. Stars under the fold. Points in a widget they never open. A ticket that starts from zero.

This post is one feature. Shopify app integrations inside ShopGuide. What they do for the merchant. How ShopGuide itself is integrated so those partners have a conversation to join.

## What merchants say they want to read

Public threads are blunt.

On r/shopifyDev in early 2026, the first reply to "what are merchants struggling with" was messy integrations, tracking mismatches, and too many apps doing half-jobs. The line that stuck: merchants do not want more tools. They want ones that work together.

On r/shopify_growth a store review found 18 apps. Each one solved a small thing. Together they slowed the storefront and made the admin a scavenger hunt. The useful comments were not "buy a nineteenth app." They were "pick tools that share a path" and "turn one off for a week and see if anyone notices."

Operator blogs say the same thing with nicer fonts. Overlapping scripts. Dashboards that do not share data. Load time that eats conversion.

None of that is a request for a fifteenth discovery widget. It is a request for Shopify app integrations that put paid context where the shopper already is.

## The feature: partners ride the on-page agent

ShopGuide is an on-page agent. You add a theme block. During chat it reads the live Shopify Catalog API so stock, variants, and price match the warehouse.

Shopify app integrations attach to that same conversation. They do not get their own chat window.

The current set on the [integrations page](https://blog.yourshopguide.com/integrations) is the list that exists. Not a roadmap slide.

| Partner | What you already bought it for | What the shopper usually sees | What ShopGuide does with it |
| :------ | :----------------------------- | :---------------------------- | :-------------------------- |
| **Shopify Catalog API** | Products, stock, price | Search and filters | Live lookup during the reply |
| **Klaviyo** | Email and popups | A modal, then silence | Keeps the offer or capture in the conversation |
| **Judge.me** | Verified reviews | Stars under the fold | Pulls a matching review into the answer |
| **Rivyo** | Reviews and UGC | Same job, different app | Surfaces Rivyo proof inside the recommendation |
| **Smile.io** | Points and tiers | A loyalty widget | Mentions live balance or VIP status while they decide |
| **Alia** | Personalized incentives | A popup that gets closed | Holds the offer after the modal is gone |
| **Slack** | Team comms | A blank ticket | Posts customer, cart, and transcript for a handoff |

That is the merchant payoff. The review that answers "does this run large" shows up in chat. Points become a sentence, not a forgotten badge. A closed popup is not a dead offer. A human picks up with the transcript instead of "please describe your issue."

On a small catalog this is polite. On a 10,000-SKU catalog it is how the same question stops becoming a ticket.

## How ShopGuide is integrated

Three connections. Shopify app integrations only work because these three exist.

**1. Theme block.**
You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script farm for every partner.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, settings. Revenue attributed to chat sessions shows up there. You do not leave Shopify to see if the agent sold anything.

**3. Live Catalog API.**
The agent looks up products from Shopify's Catalog API during the conversation. Sold-out SKUs should not get recommended as available. Dirty titles still produce thin answers. Live stock is the part the API can keep honest.

Most partner pairings activate when both apps are installed. Slack is the exception. That one needs an incoming webhook URL in ShopGuide settings.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

Install path is the App Store listing, then the theme block, then confirm the catalog is connecting in the dashboard. Docs walk the same steps if you want the click-by-click version.

## Honest limits

Say this before you flip switches.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read.

Reviews in chat are only as good as the reviews you collected.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Slack is one-way. ShopGuide posts context into a channel. Your team still resolves in Shopify or the ShopGuide admin. You do not run the whole conversation from Slack replies.

Klaviyo does not invent a list. Popup recovery and follow-up only work if Klaviyo is actually in the store and the shopper gives an email.

The agent cannot invent metafields that live only inside another app and never in Shopify. The Catalog API keeps stock current. It does not write your descriptions.

Shopify app integrations are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What Shopify app integrations does ShopGuide support?**
Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Direct reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems, not another pixel farm.

**How do I turn a partner on?**
Install both apps. Most pairings activate when both are live. Slack needs a webhook URL pasted into ShopGuide settings.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets a structured alert with context and a link to the transcript. Resolution stays in Shopify or the ShopGuide admin so history lives in one place.
