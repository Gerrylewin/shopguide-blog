Look.

You run a store with thousands of SKUs. A customer finds one product, adds it to the cart, and then stalls. They are not sure what else they need. The search bar is useless for "what goes with this." Filters are a maze. They leave with a small basket or nothing at all.

That is the quiet AOV leak in high-SKU catalogs.

ShopGuide's agent does not ignore the cart. It reads it.

## What cart context actually means

The on-page agent has access to the current cart state through Shopify's native tools. It knows the items, the variants, the quantities, and the total so far.

When a shopper asks a question or the agent opens a conversation, that context is already there. The agent can say something useful instead of generic.

"You already have the Series 900 blender gasket. The food-grade lubricant for the motor housing is the usual next step. Want me to add it?"

Or for apparel: "That jacket is in your cart. The matching base layer in the same size is in stock. I can put it in."

No separate database. No guessing. Live cart data plus live Catalog API.

## Why this matters for merchants with big catalogs

Talk to people who run 5,000+ SKU stores and the pattern is the same. Customers buy the hero item and miss the consumables, the accessories, the compatible parts. Support gets tickets later asking "does this fit with what I bought?" The long-tail inventory stays slow movers.

Cart context turns the agent into the floor person who notices what is already chosen and fills the gap. The result shows up as larger baskets on assisted sessions. Case studies on the site put the assisted AOV lift in the 19 to 48 percent range for brands that were already running high-SKU catalogs. That lift comes from completing the order, not from discounts.

You still control the tone and the frequency. The agent is not spamming "add this too" on every page. It uses the cart as a signal for when a complement actually makes sense.

## The honest limit

If the product data is thin the recommendations will be thin. Metafields for compatibility, "goes with" relationships, or simple tags help a lot. The agent works with what you already maintain in Shopify. No extra tagging job required beyond normal catalog work.

And if a customer has an empty cart the agent falls back to pure discovery. Cart context is an amplifier, not the only mode.

## Where this sits in agentic commerce

Harley Finkelstein put it cleanly: agentic commerce can level the playing field for brands by making discovery merit-based instead of ad-based. The same logic applies inside the store. Once a customer has shown intent by putting something in the cart, the agent that can act on that intent finishes the job.

Tobi Lütke's line about making every Shopify store agent-ready is the platform side. The on-page agent that already knows the cart is the merchant side of the same shift.

You are not adding another recommendation widget that ignores the basket. You are giving the conversation the same information a good sales associate would have.

## Frequently Asked Questions

**Does the agent automatically add items to the cart?**  
It can propose and, with the right configuration, complete the add. You stay in control of how aggressive that is. Most merchants keep it as a clear suggestion the customer confirms.

**Does this work with Shopify's native cart?**  
Yes. It reads the same cart the storefront uses. No parallel cart system for the core flow.

**What about logged-out shoppers?**  
Cart context still works from the session cart. When a customer logs in later the history can enrich it further.

**Will this increase AOV on my store?**  
Stores that already see assisted sessions converting with higher baskets are the ones where cart context has the most room to work. The A/B testing layer lets you measure it against a control group so you are not guessing.

**Is there extra setup beyond the normal install?**  
No. Once the agent block is in the theme and the app is connected, cart context is available. You can tune the prompts if you want tighter control over the language.
