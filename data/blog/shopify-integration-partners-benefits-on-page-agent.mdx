Look. Most Shopify merchants are not short on apps.

They are short on the moment those apps talk to each other while a shopper is still on the page.

Reddit threads in r/shopify keep circling the same complaint. "Anyone else getting annoyed with how many apps Shopify needs for basic stuff?" Another post about a store running 37 apps, site load times measured in tens of seconds, then a purge that cut the bill and lifted conversion. The useful sentence under all of that is not "install more." It is "make the ones I already pay for show up where the hesitation happens."

That is the single feature this post covers. Connecting your existing integration partners so reviews, points, list capture, and escalations ride the same conversation as the live catalog.

## The feature: partner context in the same turn

Open ShopGuide → Settings → Integrations.

ShopGuide scans the published theme for app embeds it recognizes. Klaviyo onsite scripts. Judge.me review widgets. Smile.io loyalty launchers. The ones it finds sit at the top under "Looks like you use these," with an On your store badge.

You still paste a token or webhook for the ones that need it. Detection does not invent credentials. It stops you hunting a wall of logos for tools already on the theme.

The public list is six partners: Rivyo, Judge.me, Klaviyo, Smile.io, Alia, and Slack. Each one attaches facts to the conversation the on-page agent is already having. The shopper does not open a new tab.

## How ShopGuide itself is integrated

Three connections. That is the product.

**Theme block.** ShopGuide is an on-page agent. You drop the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script farm for every partner.

**Shopify Admin.** The dashboard sits in the Shopify admin sidebar. Home, Analytics, Path Explorer, Chat History, Integrations, Settings. Numbers live next to the rest of the store. No second login.

**Catalog API at talk time.** During the conversation the agent reads the live Shopify Catalog API. Stock, variants, metafields. Partner context attaches to that same turn. Reviews, points balance, a newsletter signup, a Slack ping. All of it in one place.

That wiring is why the partners matter. The scan finds what is already live. The conversation is the place those facts get used.

## What each partner actually does

Keep the ones you run. Leave the rest alone.

**Judge.me and Rivyo.** Verified reviews and photo proof inside the answer. A shopper asks which moisturizer works for sensitive skin. The agent can quote a real review instead of inventing confidence. You paste a public API token. No token, no review text.

**Klaviyo.** The conversation does not die when the visitor leaves. Newsletter capture on the storefront. Profile tags from what they asked. Events the docs name: ShopGuide Chat Engaged, ShopGuide Order Attributed, ShopGuide NPS Submitted. Klaviyo still owns the flow. ShopGuide hands it the moment.

**Smile.io.** Points balance, VIP tier, what Gold actually gets them. The shopper can ask "how many points do I have?" and get a number. You generate an API token in Smile.io and paste it on the card. No token, the agent cannot see the balance.

**Alia.** Openings and picks that match the incentive you already decided to show that visitor. Alia stays the personalization engine. ShopGuide reads the context so the first line is not generic.

**Slack.** Stuck thread, high cart, "I want a human." Slack gets the alert with customer, cart, and a transcript link. Your team does not reply inside Slack. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.

Docs also mention WhatsApp handoff and Sidekick tools inside Shopify Admin. Those are real. They are not on the public partner page. The page is the six logos above. Sidekick is native Shopify, not a third-party tile.

## What merchants actually say they want to read

The stack is paid for. Reviews live in Judge.me or Rivyo. Email lives in Klaviyo. Points live in Smile.io. The on-page agent still talks like none of that exists.

Automatic detection plus partner context is built for that sentence. It does not uninstall your stack. It does not add a seventh review app. It finds Klaviyo and Judge.me on the theme you already published, then lets those facts ride the same conversation as the catalog.

Limits, said plainly.

Detection is a heuristic. It only sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Dirty product data still produces thin answers. The Catalog API keeps stock honest. It does not write your descriptions.

Slack is one-way. Klaviyo, Smile.io, and the review apps need a key or token. A partial stack still works. You do not need every logo.

That is the deal. Native wiring. Partner context when it exists. Not a new operating system.

## Frequently Asked Questions

**What do Shopify integration partners actually do inside ShopGuide?**
They attach the facts you already store elsewhere to the on-page conversation. Reviews from Judge.me or Rivyo. Points and tiers from Smile.io. Newsletter capture and events into Klaviyo. Escalation alerts into Slack. Alia for incentive context. All of it in the same turn as the Catalog API.

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Direct reads from the Shopify Catalog API during chat. Partner apps attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. Partners are not copied onto the page as extra pixels. The agent reads those systems during the conversation.

**How do I turn a partner on?**
Detection badges what it finds on the published theme. Klaviyo, Smile.io, Judge.me, and Rivyo still need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on by default.

**What if I only use some of the partners?**
Use the ones you run. A partial stack still works. You do not need every logo on the integrations page.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
