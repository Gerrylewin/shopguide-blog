Most Shopify merchants do not want another dashboard.

They want the apps they already pay for to show up where the shopper is deciding.

Look at the integrations page. Six cards. Rivyo, Judge.me, Klaviyo, Smile.io, Alia, Slack.

That is the current list. Not a roadmap.

One feature. Those partners ride the same on-page conversation. The shopper does not have to hunt for a review, a points balance, or an offer that just closed.

![Retail checkout, the moment the stack should already know who is standing there](https://images.unsplash.com/photo-1556742049-0cfed4f6a45d?w=1200&q=80)

## What merchants actually say

Public threads are blunt.

On r/ecommerce a merchant running Klaviyo, LoyaltyLion, and Yotpo wrote that the apps all sync. Data flows. But none of them reason across the combined data while the shopper is still on the page. The agency bill for stitching segments by hand was $3-5k a month.

On r/shopify_growth someone listed 18 apps. Each one solved a small thing. Together they slowed the store and no one on the team could say what half of them even did.

Loyalty gets the same complaint. A points program exists. Customers cannot see the balance without logging in. No reminder. "A loyalty program nobody interacts with is just a cost centre."

None of that is a request for a fifteenth widget. It is a request for the paid context to appear in the conversation that is already happening.

## The feature: partners ride the on-page conversation

ShopGuide is an on-page agent. It lives in a theme block you add in the theme editor. Launch messages, visibility, and styling live in the app admin.

It reads the live Shopify Catalog API during chat so stock, variants, and price match the warehouse.

Shopify integration partners attach to that same turn. They do not get their own chat window. They do not get a second script farm.

Here is what each one actually does today:

| Partner | What you bought it for | What ShopGuide does with it | Merchant payoff |
| :-- | :-- | :-- | :-- |
| **Shopify Catalog API** | Products, stock, price | Live lookup during the reply | Answers match the warehouse, not last week's snapshot |
| **Klaviyo** | Email, SMS, popups | Captures the email, tags the profile, fires named chat events | Strong conversations do not die when the visitor bounces |
| **Judge.me** | Verified reviews | Pulls a matching review and photo proof into the answer | Social proof stays in the flow |
| **Rivyo** | Reviews and UGC | Surfaces Rivyo proof inside the recommendation | Same trust job if Rivyo is your review app |
| **Smile.io** | Points and VIP tiers | Reads live balance and tier, answers "how many points do I have?" | Dormant points become a reason to buy now |
| **Alia** | Personalized incentives | Keeps the Alia offer in context after the popup closes | The discount does not die with the modal |
| **Slack** | Team comms | Posts customer, cart, and a transcript link | Humans pick up without starting from zero |

That is the value. A review that answers "does this run large" shows up in chat. Points become a sentence. A closed popup is not a dead offer. A human gets the transcript and cart instead of "please describe your issue."

On a small catalog this is convenient. On a 10,000-SKU store it is how the same question stops becoming a ticket.

## How ShopGuide is integrated into Shopify

Three connections. The partners only work because these three exist.

**1. Theme block.** You add the ShopGuide Chat section in the theme editor. One storefront surface. Not a new script for every partner.

**2. Shopify Admin.** The dashboard sits in the Shopify admin sidebar. Analytics, chat history, Integrations, Settings. Revenue attributed to chat sessions shows up there. No second login.

**3. Catalog API at talk time.** The agent looks up products from Shopify's Catalog API during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. Sold-out SKUs should not get recommended as available.

That wiring is why the cards on the integrations page matter. The conversation is the place those facts get used.

Open **ShopGuide → Settings → Integrations** in Shopify admin. ShopGuide checks your published theme for app embeds it recognizes and badges the ones it sees. You still paste the credentials.

- Klaviyo needs a private API key with the right scopes.
- Judge.me and Rivyo need the public API token.
- Smile.io needs an API token from Smile admin.
- Slack needs an incoming webhook URL.
- Alia is on when your polls are active.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

## Honest limits

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read.

Detection is a heuristic. An app installed but not embedded on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Klaviyo still owns the flow. ShopGuide hands it the moment. Follow-up only works if the shopper gives an email.

Slack is a one-way webhook. Your team resolves in Shopify or the ShopGuide admin, not by replying in Slack.

The Catalog API keeps stock honest. It does not write your descriptions. Dirty product data still produces thin answers.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on when polls are active.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.
