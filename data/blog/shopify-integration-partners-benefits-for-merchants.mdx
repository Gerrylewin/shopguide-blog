Open the Shopify subreddits and the complaint is consistent.

Not "I need another dashboard."

"I already pay for Klaviyo. I already pay for reviews. Why does the shopper still have to hunt for them?"

That is the job of Shopify integration partners. The apps you already run show up in the same conversation where the shopper is deciding. Not in a separate tab. Not behind a closed popup. Not in a ticket that starts from zero.

This post is about one feature. The partner set on the [integrations page](https://blog.yourshopguide.com/integrations). What each one does for the merchant. How ShopGuide itself is wired into Shopify so those partners have somewhere to talk. What they will not do.

## What merchants actually want

Public threads are not subtle.

Stores run 5 to 18 apps. Each one solves a piece. Together they create a mess of dashboards, fragile Zapier flows, and scripts that slow the store. One founder on r/shopify_growth walked a store with 18 apps. Nobody on the team could say what half of them did. Another thread called it the app tax. Monthly cost plus the performance hit.

Loyalty gets the same treatment. Points programs exist. Customers cannot see a balance without logging in. No reminder. "The program existed but was essentially invisible." Smile.io threads say the same thing in fewer words. The biggest issue is how invisible it is.

None of that is a request for a fifteenth widget. It is a request for the paid context to show up where the shopper already is.

Shopify integration partners answer that request. The list that exists today lives on the integrations page: Rivyo, Judge.me, Klaviyo, Smile.io, Alia, Slack. Plus the native Shopify Catalog API.

## The feature: partners ride the on-page conversation

ShopGuide is an on-page agent. It lives in a theme block. It reads the live Shopify Catalog API during chat so stock, variants, and price match the warehouse.

Shopify integration partners attach to that same conversation. They do not get their own chat window. They do not get a second script farm.

Here is what each one actually does:

| Partner | What you bought it for | What the shopper usually sees | What ShopGuide does with it |
| :------ | :--------------------- | :---------------------------- | :-------------------------- |
| **Shopify Catalog API** | Products, stock, price | Search and filters | Live lookup during the reply |
| **Klaviyo** | Email, SMS, popups | A modal, then silence | Captures the email, tags the profile, fires named chat events |
| **Judge.me** | Verified reviews | Stars under the fold | Pulls a matching review and photo proof into the answer |
| **Rivyo** | Reviews and UGC | Same job, different app | Surfaces Rivyo proof inside the recommendation |
| **Smile.io** | Points and VIP tiers | A loyalty widget | Reads live balance and tier, answers "how many points do I have?" |
| **Alia** | Personalized incentives | A popup that gets closed | Keeps the Alia offer in context after the modal is gone |
| **Slack** | Team comms | A blank ticket | Posts customer, cart, and a transcript link for a handoff |

The merchant payoff is concrete.

The review that answers "does this run large" shows up in chat instead of on a tab the shopper never opens. Points become a sentence. A closed popup is not a dead offer. A human picks up with the transcript instead of "please describe your issue."

On a small catalog this is polite. On a high-SKU store it is how the same question stops becoming a ticket.

Klaviyo is the clearest handoff. The docs name the events: ShopGuide Chat Engaged, ShopGuide Order Attributed, ShopGuide NPS Submitted. Profile fields that land include journey archetype, persona, last chat intent, key hesitation, and dietary tags. Dietary tags stay on verifiable attributes. Not a vibe the model guessed. Klaviyo still owns the flow. ShopGuide hands it the moment.

## How ShopGuide is integrated into Shopify

Three connections. Shopify integration partners only work because these three exist.

**1. Theme block.**
You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, chat history, Integrations, Settings. Revenue attributed to chat sessions shows up there. There is no second login to babysit.

**3. Catalog API at talk time.**
The agent looks up products from Shopify's Catalog API during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. Sold-out SKUs should not get recommended as available.

That wiring is why the partner cards matter. The conversation is the place those facts get used.

Automatic app detection helps. Open Settings → Integrations. ShopGuide checks the published theme for app embeds it recognizes. Those apps land at the top under "Looks like you use these," with an On your store badge. You still paste the key or token. Detection stops you from hunting through logos.

## How to connect them

Open **ShopGuide → Settings → Integrations** in Shopify admin.

- **Klaviyo:** paste a private API key with Profiles, Events, and Lists write access. Pick the newsletter list.
- **Judge.me and Rivyo:** paste the public API token from that app.
- **Smile.io:** generate an API token in Smile admin and paste it on the card.
- **Slack:** create an incoming webhook for the channel and paste the URL.
- **Alia:** on when your Alia polls are active. No token paste.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

New to ShopGuide? Install from the App Store listing, add the theme block, then confirm the catalog is syncing in the dashboard. The [docs](https://docs.yourshopguide.com/docs/advanced-features/ecosystem-integrations) walk the same steps.

Docs also mention WhatsApp handoff and Sidekick tools inside Shopify Admin. Those are real. They are not tiles on the public partner page. The page is the six logos. Sidekick is native Shopify.

## Honest limits

Say this before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read. Installing ShopGuide does not remove the scripts those apps already inject. The point is not a seventh app that does their jobs. The point is one place those facts get used.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified, and only for what the token can read. A first-time anonymous visitor has no points to surface. If Smile's plan hides that data, ShopGuide cannot invent it. Visibility is the job. Redemption is still yours.

Klaviyo still owns the flow. ShopGuide hands it the moment. Follow-up only works if the shopper gives an email.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin, not by replying in Slack.

The Catalog API keeps stock honest. It does not write your descriptions. Dirty product data still produces thin answers.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on when polls are active.

**Does ShopGuide find my apps automatically?**
It badges apps it recognizes on your published theme, so you know which cards to fill in. You still paste the credentials. See [automatic app detection](/blog/automatic-app-detection-shopify-integration-partners).

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
