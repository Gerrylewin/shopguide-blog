Shopify merchants are tired of the app tax.

Not the monthly bill. The way the tools they already bought never talk to each other while the shopper is deciding.

Popup in one corner. Stars under the fold. Points in a widget nobody opens. A human ticket that starts from zero.

That is what the public threads keep saying. On r/shopify_growth someone counted 18 apps on one store. Each one fixed a small thing. Together they slowed the site and made the admin confusing. Cleaning the stack helped more than adding another install.

On r/shopifyDev the top answer to "what are merchants actually struggling with" was messy integrations and too many apps doing half-jobs. The line that stuck: merchants do not want more tools. They want ones that work together.

So that is the post. One feature. Partner context in the conversation you already have.

![Person shopping on a laptop](https://images.unsplash.com/photo-1556740738-b6a63e27c4df?w=1200&q=80)

## The feature: partners ride the on-page agent

ShopGuide is one theme block. You drop the ShopGuide Chat section into the theme editor. Launch messages, visibility, and styling live in the Shopify admin. One storefront surface.

While the shopper talks, the agent reads the live Shopify Catalog API. Stock. Variants. Price. Metafields.

Shopify integration partners attach to that same turn. They do not get a second bubble. They do not get a new script farm.

The current list is on the [integrations page](https://blog.yourshopguide.com/integrations). Six partners. No coming-soon row.

**Judge.me.** Verified reviews and photo proof land inside the answer. Shopper asks if the jacket runs large. The reply can quote a real review instead of guessing. You paste a public API token.

**Rivyo.** Same job if Rivyo is the review app you already run. UGC rides the recommendation instead of living under the fold.

**Klaviyo.** The conversation does not die when the visitor leaves. Newsletter capture on the storefront. Profile tags from what they asked. The events the docs actually name: ShopGuide Chat Engaged, ShopGuide Order Attributed, ShopGuide NPS Submitted. Klaviyo still owns the flow. ShopGuide hands it the moment.

**Smile.io.** Live points balance. VIP tier. What Gold actually gets them. A shopper can ask "how many points do I have?" and get a number. You generate an API token in Smile and paste it on the card.

**Alia.** Personalized incentives stay in context after the popup closes. Alia stays the personalization engine. ShopGuide reads what you already decided to show that visitor.

**Slack.** Stuck thread. High cart. "I want a human." Slack gets the alert with customer, cart, and a transcript link. Your team does not reply inside Slack. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.

That is the merchant payoff of Shopify app integrations done this way.

The review that closes the sale shows up in the chat.

Dormant points become a sentence.

A closed popup is not a dead offer.

A human picks up with the transcript instead of "please describe your issue."

## How ShopGuide is integrated

Three connections. That is why the partners have somewhere to talk.

**1. Theme block.**
One storefront surface. Not a new script for every partner.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home. Analytics. Test your Guide. Chat history. Integrations. Settings. Revenue attributed to chat sessions shows up there. No second login.

**3. Catalog API at talk time.**
The agent looks up products from Shopify's Catalog API during the conversation. Partner context attaches to that same reply. Sold-out SKUs should not get recommended as available.

Open **ShopGuide → Settings → Integrations** and the app scans your published theme for embeds it recognizes. Klaviyo onsite. Judge.me widgets. Smile.io launchers. Detected apps land at the top under "Looks like you use these" with an **On your store** badge.

The badge is a map. It does not invent credentials. You still paste a key or token for Klaviyo, Judge.me, Rivyo, and Smile.io. Slack still wants an incoming webhook URL. Alia is on by default when your Alia polls are active.

You do not have to connect every logo. A store on Judge.me and Klaviyo does not need Rivyo for the agent to be useful.

Docs also mention WhatsApp handoff and Sidekick tools inside Shopify Admin. Those are real. They are not tiles on the public partner page. The page is the six logos above. Sidekick is native Shopify.

## What this will not do

Say it before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Klaviyo still owns the email. Follow-up only works if the shopper gives an address.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin.

The Catalog API keeps stock honest. It does not write your descriptions. Thin product data still produces thin answers.

Shopify integration partners here are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What Shopify app integrations does ShopGuide support?**
Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list is on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on by default.

**Does ShopGuide find my apps automatically?**
It badges apps it recognizes on your published theme so you know which cards to fill in. You still paste the credentials. See [automatic app detection](/blog/automatic-app-detection-shopify-integration-partners).

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
