Open a merchant thread and the complaint is rarely "I need a new logo."

It is "the apps I already pay for do not talk to each other."

That is the job. Shopify apps that work together means the email list, the reviews, the points, and the human handoff show up in the same place the shopper is already asking a question. Not in a popup they closed. Not under the fold. Not in a ticket that starts from zero.

ShopGuide does one thing with that stack. It reads the partners you already run and uses them inside the on-page conversation.

![A clothing rack behind glass, the kind of catalog a shopper has to walk](https://images.unsplash.com/photo-1445205170230-053b83016050?w=1200&q=80)

## What merchants actually say

Public threads are blunt.

On February 21, 2026, r/shopifyDev asked what merchants are struggling with. The top reply, from u/EngineeringHuge1331, was the small daily stuff. Messy integrations. Tracking mismatches. Too many apps doing half-jobs. The line that matters: "Merchants don't want more tools they want ones that actually work together."

Loyalty gets the same treatment. On April 24, 2026, a Smile.io thread on r/shopifyDev had u/Rich-Pass-3280 drop the program after a few months. "biggest issue for us was how invisible it is to customers. unless someone is actively looking for it they don't even notice it exists."

An October 22, 2025 post on r/shopify made the same point from the other side of the counter. A merchant on Smile's Starter plan could not find a way for a logged-in customer to see a points balance. The program existed. The shopper could not see it. That is a cost, not a loyalty system.

None of that is a request for a fifteenth widget. It is a request for Shopify apps that work together at the moment of the question.

## The feature: partner facts ride the reply

ShopGuide is an on-page agent. It lives in a theme block. During chat it looks up the live Shopify Catalog API so stock, variants, and price match the warehouse.

Shopify apps that work together, in this product, means the partner apps attach to that same turn. They do not get their own chat window.

The list on the [integrations page](https://blog.yourshopguide.com/integrations) is the set that exists today. Not a roadmap.

| Partner                 | What you already pay it for | What the shopper usually sees | What shows up in the conversation                     |
| :---------------------- | :-------------------------- | :---------------------------- | :---------------------------------------------------- |
| **Shopify Catalog API** | Products, stock, price      | Search and filters            | Live inventory, variants, and price in the reply      |
| **Klaviyo**             | Email, SMS, onsite popups   | A modal, then silence         | Captured email, profile tags, named chat events       |
| **Judge.me**            | Verified reviews            | Stars under the fold          | A matching review and photo proof in the answer       |
| **Rivyo**               | Reviews and UGC             | Same job, different app       | Rivyo proof inside the recommendation                 |

| **Alia**                | Personalized incentives     | A popup that gets closed      | The offer stays in context after the modal is gone    |
| **Slack**               | Team comms                  | A blank ticket                | Customer, cart, and a transcript link for the handoff |

That is the merchant payoff. A "does this run large" question can pull the review that answers it. A points balance can become a sentence instead of a badge nobody opens. A closed popup is not a dead offer. A human picks up with the cart and the transcript instead of "please describe your issue."

On a 200-SKU boutique this is polite. On a 10,000-SKU catalog it is how the same question stops becoming a ticket.

The partner-by-partner map, with connect steps, already lives in the [integration partners guide](/blog/shopify-integration-partners-existing-stack). This post is the reason those pairings exist.

## How ShopGuide is integrated

Three connections. The partner cards only matter because these three exist.

**1. Theme block.**
You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**2. Shopify admin.**
The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, chat history, Integrations, Settings. Revenue attributed to chat sessions shows up there. There is no second login to babysit.

**3. Catalog API at talk time.**
The agent looks up products from Shopify's Catalog API during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. A sold-out SKU should not get recommended as available.

That is how ShopGuide is integrated. A theme block. A native admin app. Live catalog reads. Shopify apps that work together plug into that conversation. They do not replace it.

Docs also cover WhatsApp handoff and nine Sidekick tools inside Shopify admin. Those are real. They are not tiles on the public [integrations page](https://blog.yourshopguide.com/integrations). The page is Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack. Sidekick is native Shopify, not a third-party card.

## How you turn a partner on

Open **ShopGuide → Settings → Integrations**.

ShopGuide scans the published theme for app embeds it recognizes. Those apps land at the top under "Looks like you use these," with an **On your store** badge. That tells you which cards to fill in. It does not connect them.

Then paste what that partner actually needs:

- **Klaviyo:** a private API key with Profiles, Events, and Lists write access, plus the newsletter list. Named events are ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted.
- **Judge.me and Rivyo:** the public API token from that app.
- **Smile.io:** an API token from Smile admin.
- **Slack:** an incoming webhook URL for the channel.
- **Alia:** on when your polls are active. No token paste.

You do not have to connect every card. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

Install from the [Shopify App Store](https://apps.shopify.com/shopguide), add the theme block, confirm the catalog is syncing, then connect the partners you run. The [docs](https://docs.yourshopguide.com/docs/advanced-features/ecosystem-integrations) walk the same clicks. How the theme scan works: [automatic app detection](/blog/automatic-app-detection-shopify-integration-partners).

## Honest limits

Say this before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or the token is wrong, there is nothing to read.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not embedded will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface. If the plan you bought does not let the customer see a balance, the agent cannot invent one. Visibility is the job. Redemption is still yours. The April and October threads are right about that.

Klaviyo still owns the flow. ShopGuide hands it the moment. Follow-up only works if the shopper gives an email.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin, not by replying in Slack.

The Catalog API keeps stock honest. It does not write your descriptions. Dirty product data still produces thin answers.

Shopify apps that work together are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What does "Shopify apps that work together" mean in ShopGuide?**
The apps you already run show up inside the on-page conversation. Today that is Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus live reads from the Shopify Catalog API. The public list is on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings, then Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token. Slack needs an incoming webhook URL. Alia is on when polls are active. Detection badges apps it finds on the published theme. You still paste the credentials.

**Will this add more scripts to the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
