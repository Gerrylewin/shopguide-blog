Look.

You pay for Klaviyo. You pay for reviews. You pay for loyalty. You have a Slack channel.

None of that helps the shopper who is staring at the product page right now.

The popup closes. The stars sit under the fold. The points widget needs a login. The support ticket starts from zero.

That is the gap Shopify integration partners are meant to close. Not another app. The ones you already run, visible in the conversation.

Reddit is full of the same complaint. Merchants on r/shopifyDev say the real struggle is messy integrations and too many apps doing half-jobs. On r/shopify_growth someone cleaned 18 apps and got more lift from removing them than from adding another. Loyalty programs that live in a widget nobody opens are just cost centers. People want the tools they already bought to show up at the same time.

ShopGuide does not replace those tools. It is the on-page agent that can read them while the shopper is deciding.

## The feature: partners in the same conversation

ShopGuide is one theme block. You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the Shopify admin. One surface. Not a new script farm.

While the shopper talks, the agent reads the live Shopify Catalog API. Stock. Variants. Price. Sold-out items do not get recommended as available.

The partners on the [integrations page](https://blog.yourshopguide.com/integrations) attach to that same reply.

**Judge.me.** Verified reviews and photo proof land inside the answer. Shopper asks if the jacket runs large. The reply can quote a real review instead of guessing. Paste a public API token.

**Rivyo.** Same job if Rivyo is the review app you use. UGC rides the recommendation.

**Klaviyo.** The conversation does not die when the visitor leaves. Newsletter capture on the storefront. Profile tags from what they asked. The events the docs name are ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted. Klaviyo still owns the flow. ShopGuide hands it the moment.

**Smile.io.** Live points balance. VIP tier. What Gold actually gets them. A shopper can ask how many points they have and get a number. Generate an API token in Smile.io and paste it on the card.

**Alia.** Personalized incentives stay in context after the popup closes. Alia stays the personalization engine. ShopGuide reads what you already decided to show that visitor.

**Slack.** Stuck thread. High cart. "I want a human." Slack gets the alert with customer, cart, and a transcript link. Your team does not reply inside Slack. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.

That is the merchant payoff of Shopify integration partners done this way.

The review that closes the sale shows up in the chat.

Dormant points become a sentence.

A closed popup is not a dead offer.

A human picks up with the transcript instead of "please describe your issue."

## How ShopGuide is integrated into Shopify

Shopify integration partners only work because ShopGuide is wired into Shopify, not parked next to it.

Three connections.

**1. Theme block.** You add the ShopGuide Chat section in the theme editor. One storefront surface. Partner apps keep their own scripts. ShopGuide does not install a second copy of Klaviyo or Judge.me.

**2. Shopify Admin.** The dashboard sits in the Shopify admin sidebar. Home. Analytics. Chats. Integrations. Settings. Revenue attributed to chat sessions shows up there. No second login.

**3. Catalog API at talk time.** The agent looks up products from Shopify's Catalog API during the conversation. Partner context attaches to that same reply.

Open **ShopGuide → Settings → Integrations** and the app scans your published theme for embeds it recognizes. Klaviyo onsite. Judge.me widgets. Smile.io launchers. Detected apps land at the top under "Looks like you use these" with an **On your store** badge.

The badge is a map. It does not invent credentials. You still paste a key or token for Klaviyo, Judge.me, Rivyo, and Smile.io. Slack still wants an incoming webhook URL. Alia is on by default when your Alia polls are active.

You do not have to connect every logo. A store on Judge.me and Klaviyo does not need Rivyo for the agent to be useful.

## What this will not do

Say it before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Klaviyo still owns the email. Follow-up only works if the shopper gives an address.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin.

The Catalog API keeps stock honest. It does not write your descriptions. Thin product data still produces thin answers.

Shopify integration partners here are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list is on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on by default.

**Does ShopGuide find my apps automatically?**
It badges apps it recognizes on your published theme so you know which cards to fill in. You still paste the credentials.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
