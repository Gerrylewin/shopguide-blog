Merchants do not post on Reddit asking for more apps.

They post about the ones they already have sitting in separate corners. A Klaviyo popup that gets closed. Judge.me stars under the fold. Smile.io points that nobody sees until they log in. A Slack ticket that starts with "please describe your issue."

That is the actual complaint. Not that the tools are bad. That they never meet the shopper in the same place.

ShopGuide's job here is narrow. Put an on-page agent on the storefront. Read the live catalog. Pull the partner facts you already pay for into that same conversation. Hand the transcript to a human when it is stuck.

This is the guide. One feature. Partner context in the path. What each one does. How ShopGuide is wired into Shopify so the partners have somewhere to land. What it will not do.

## What merchants keep saying

The threads are consistent.

On r/shopify_growth in February 2026 a founder described a store with 18 apps. Each one fixed a small thing. Together they slowed the store and made the backend a mess. The useful replies were not "install a better one." They were that nobody on the team could still explain what half of them did.

The same month on r/shopifyDev the top answer to "what are merchants actually struggling with" was the small daily stuff. Messy integrations. Too many apps doing half-jobs. One line stuck: "Merchants don't want more tools they want ones that actually work together."

Loyalty gets called out the same way. A points program that exists but is invisible. Customers cannot see a balance without logging in. No reminder. "A loyalty program nobody interacts with is just a cost centre."

Reviews and email sit in the same category. The data is there. The shopper never sees it at the moment they are deciding.

None of that is a request for a fifteenth widget. It is a request for the paid context to show up where the shopper already is.

## The feature: partners ride the on-page conversation

ShopGuide is an on-page agent. It lives in a theme block you add in the theme editor. It reads the Shopify Catalog API during chat so stock, variants, and price match what is actually available.

Shopify integration partners attach to that same conversation. They do not get a second chat window. They do not get their own script on the page.

The list on the [integrations page](https://blog.yourshopguide.com/integrations) is the current set. Not a roadmap.

| Partner | What you bought it for | What ShopGuide does with it | Merchant payoff |
| --- | --- | --- | --- |
| **Shopify Catalog API** | Products, stock, price | Live lookup during the reply | Answers match the warehouse, not last week's export |
| **Klaviyo** | Email, SMS, popups | Captures the email, tags the profile, fires named chat events | A closed popup is not a dead list signup |
| **Judge.me** | Verified reviews | Pulls matching review and photo proof into the answer | Social proof at the decision, not below the fold |
| **Rivyo** | Reviews and UGC | Surfaces Rivyo proof inside the recommendation | Same trust job if Rivyo is your review app |
| **Smile.io** | Points and VIP tiers | Reads live balance and tier, answers "how many points do I have?" | Dormant points become a reason to buy now |
| **Alia** | Personalized incentives | Keeps the Alia offer in context after the modal closes | The discount does not die with the popup |
| **Slack** | Team comms | Posts customer, cart, and a transcript link | Human picks up with context instead of a blank ticket |

That is the payoff in practice.

The review that answers "does this run large" shows up in chat. Points become a sentence ("you have 500 points, that is $5 off today") instead of a badge the shopper never opens. A closed popup still captures the email. A human sees the transcript and the cart.

On a small catalog this is convenient. On a 10,000-SKU store it is how the same question stops becoming a ticket.

Klaviyo is the clearest example of the handoff. The docs name the payload. Three events: ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted. Profile fields that land include `sg_journey_archetype`, `sg_persona`, `sg_last_chat_intent`, `sg_key_hesitation`, and `sg_dietary_tags`. Dietary tags stay on verifiable attributes (gluten-free, certified organic, non-GMO, raw). Not a lifestyle guess. Klaviyo still owns the flow. ShopGuide hands it the moment.

## How ShopGuide is integrated into Shopify

Three connections. The partners only work because these three exist.

**1. Theme block.** You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script for every partner.

**2. Shopify Admin.** The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, chat history, Integrations, Settings. Revenue attributed to chat sessions shows up there. No second login.

**3. Catalog API at talk time.** The agent looks up products from Shopify's Catalog API during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. Sold-out SKUs should not get recommended as available.

That wiring is why the partner cards matter. The conversation is the place those facts get used.

## How to connect a partner

Open **ShopGuide → Settings → Integrations** in Shopify admin.

ShopGuide checks your published theme for app embeds it recognizes. Those apps land at the top under "Looks like you use these," with an **On your store** badge. That saves you hunting through logos. It does not connect anything by itself.

Then connect the ones you run:

- **Klaviyo:** paste a private API key with Profiles, Events, and Lists write access. Pick the newsletter list. Named events are ShopGuide Chat Engaged, ShopGuide Order Attributed, and ShopGuide NPS Submitted.
- **Judge.me and Rivyo:** paste the public API token from that app.
- **Smile.io:** generate an API token in Smile admin and paste it on the card.
- **Slack:** create an incoming webhook for the channel and paste the URL.
- **Alia:** on when your Alia polls are active. No token paste.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

New to ShopGuide? Install from the App Store listing, add the theme block, then confirm the catalog is syncing in the dashboard. The [docs](https://docs.yourshopguide.com/docs/advanced-features/ecosystem-integrations) walk the same steps.

## Honest limits

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read. Installing ShopGuide does not remove the scripts those apps already inject. The point is not a seventh app that does their jobs. The point is one place those facts get used.

Detection is a heuristic. It sees app embeds on the published theme. An app installed but not on the theme will not badge itself. Connect it by hand.

Reviews in chat are only as good as the reviews you collected. An empty review catalog means empty social proof.

Smile.io only helps once the shopper is identified, and only for what the token can read. A first-time anonymous visitor has no points to surface. If Smile's plan hides that data, ShopGuide cannot invent it. Visibility is the job. Redemption is still yours.

Klaviyo still owns the flow. ShopGuide hands it the moment. Follow-up only works if the shopper gives an email. Dietary tags only land on verifiable attributes, not on a lifestyle guess.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team resolves in Shopify or the ShopGuide admin, not by replying in Slack.

The Catalog API keeps stock honest. It does not write your descriptions. Dirty product data still produces thin answers.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
The apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The public list lives on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Live reads from the Shopify Catalog API during chat. Partners attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How do I turn a partner on?**
Open Settings → Integrations. Klaviyo, Judge.me, Rivyo, and Smile.io each need an API key or token pasted on their card. Slack needs an incoming webhook URL. Alia is on when polls are active.

**Does ShopGuide find my apps automatically?**
It badges apps it recognizes on your published theme, so you know which cards to fill in. You still paste the credentials. See [automatic app detection](/blog/automatic-app-detection-shopify-integration-partners).

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
