Merchants are not asking for another tile.

They are asking for the tools they already pay for to show up when a shopper stalls.

That sentence keeps showing up in public. On [r/shopifyDev](https://www.reddit.com/r/shopifyDev/comments/1rarbr9/) someone asked what merchants were actually struggling with in 2026. The top reply was messy integrations, tracking mismatches, and too many apps doing half-jobs. The line that stuck: merchants do not want more tools. They want ones that work together.

On [r/shopify_growth](https://www.reddit.com/r/shopify_growth/comments/1r858s7/we_had_18_apps_on_a_shopify_store_and_it_wasnt/) an operator described an 18-app stack. Each app solved one small issue. Together they slowed the store and made the backend confusing. The fix was not a nineteenth app. It was fewer half-jobs.

Shopify integration partners exist for that gap. Not a new discovery widget. A place for the stack you already run to speak while the shopper is still deciding.

This post covers one feature: the partners on the [integrations page](https://blog.yourshopguide.com/integrations), and how ShopGuide is integrated so those partners have somewhere to talk.

## One feature: partners attach to the same conversation

ShopGuide is an on-page agent. You install it from the Shopify App Store. You add the ShopGuide Chat section in the theme editor. The admin lives in the Shopify sidebar.

During a chat the agent looks up products on the Shopify Catalog API. Stock, variants, and price come from the store. Not from a file you uploaded last Tuesday.

Shopify integration partners attach to that same conversation. They do not get their own chat window.

The current set is the list on the [ShopGuide integrations page](https://blog.yourshopguide.com/integrations). Same cards as [integrations.yourshopguide.com/shopify](https://integrations.yourshopguide.com/shopify). No "coming soon" row.

| Partner on the page | Category | What you already bought it for | What the agent does with it | Merchant payoff |
| :------------------ | :------- | :----------------------------- | :-------------------------- | :-------------- |
| **Shopify Catalog API** | Native Shopify | Products, stock, price | Live lookup during the reply | Answers match inventory |
| **Klaviyo** | Acquisition | Email and popups | Keeps an offer or capture in chat. Can sync Path Explorer lists | The conversation and the list stop living in two rooms |
| **Judge.me** | Reviews | Verified reviews | Pulls a matching review and photo proof into the answer | Social proof at the decision, not under the fold |
| **Rivyo** | Reviews | Reviews and UGC | Surfaces Rivyo proof inside the recommendation | Same job if Rivyo is the review app you kept |
| **Smile.io** | Upsells | Points and VIP tiers | Mentions live balance or status while they decide | Dormant points become a reason to check out |

| **Slack** | Customer Support | Team channel | Posts customer, cart, and transcript on a handoff | Humans start mid-sentence instead of from a blank ticket |

That is the value. The review that answers "does this run large" shows up in chat. Points become a sentence. A closed popup is not a dead offer. A human picks up with the transcript.

On a 200-SKU boutique this is polite. On a 10,000-SKU catalog it is how the same question stops becoming a ticket.

Connect the ones you run. Leave the rest alone.

## How ShopGuide itself is integrated

Three connections. Shopify integration partners only work because these three exist.

**1. Theme block.**
You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Not a new script farm for every partner.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home, analytics, Test your Guide, Integrations, Settings. Chat-attributed revenue shows up there. Review-app tokens live on the Integrations screen. You do not leave Shopify to see if a conversation sold anything.

**3. Live Catalog API.**
The agent queries Shopify's Catalog API for the products in play. Sold-out SKUs should not get recommended as available. Dirty titles still produce thin answers. Live stock is the part the API can keep honest. Details live in the [live Catalog API post](/blog/live-catalog-api-keeps-agent-answers-accurate-high-sku-shopify).

Most pairings activate when both apps are installed. Slack is the exception. That one needs an incoming webhook URL in ShopGuide settings.

There is a second Klaviyo path that is easy to miss if you only look at storefront chat. Path Explorer can sync reachable segments into a Klaviyo list with cohort properties. Cart abandoners and chat-assisted buyers can land in a flow you already run. That is documented. It is not a promise that every anonymous browser becomes a profile.

You do not have to connect every partner. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

## Why merchants use Shopify integration partners

High-SKU operators already run a lean version of the same kit. Email. Reviews. Loyalty. A channel for the team. Maybe a popup tool.

The complaint is not "I hate apps." It is paying for tools that never share context at the moment the shopper hesitates.

Popup in one corner. Stars below the fold. Points in a widget they never open. A human ticket that starts from zero.

Shopify integration partners do not ask you to rip Klaviyo out. They ask the agent to use Klaviyo. Same for reviews and points.

The useful test is boring. Can the shopper hear the thing you already paid for without opening another tab?

That is why the partner page is short on purpose. Six names. The catalog underneath them. Connect what you already run.

## Honest limits

Say this before you flip switches.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or the token is wrong, there is nothing to read.

Reviews in chat are only as good as the reviews you collected.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Slack is one-way. ShopGuide posts context into a channel. Your team still resolves in Shopify or the ShopGuide admin. You do not run the whole conversation from Slack replies.

Klaviyo does not invent a list. Popup recovery needs Klaviyo actually on the store. Path Explorer sync only pushes reachable people, the ones with an email or a Shopify customer id.

The agent cannot invent metafields that live only inside another app and never in Shopify. The Catalog API keeps stock current. It does not write your descriptions.

Shopify integration partners are context in the path. They are not a new operating system for the store.

## Frequently Asked Questions

**What are Shopify integration partners in ShopGuide?**
They are the apps ShopGuide can read from or write to during a guided session: Klaviyo, Judge.me, Rivyo, Smile.io, Alia, and Slack, plus the native Shopify Catalog API. The current cards live on the [integrations page](https://blog.yourshopguide.com/integrations).

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Direct reads from the Shopify Catalog API during chat. Partner apps attach to that same conversation.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. It does not install a second copy of Klaviyo or Judge.me. Partner apps keep their own scripts. The integration is the agent reading those systems, not another pixel farm.

**How do I turn a partner on?**
Install both apps. Most pairings activate when both are live. Slack needs a webhook URL pasted into ShopGuide settings.

**What if I only use some of the partners?**
Use the ones you have. Partial stacks still work.

**Does Slack let my team reply inside Slack?**
No. Slack gets a structured alert with context and a link to the transcript. Resolution stays in Shopify or the ShopGuide admin so history lives in one place.
